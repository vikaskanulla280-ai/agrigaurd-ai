AGRIGUARD AI — FULL CODE CAPABILITIES & FEATURES

1. Multimodal Leaf AI Diagnostics
- Browser-Based Base64 Processing: Converts uploaded leaf photos (JPG/PNG) into base64 format directly inside the browser.
- Gemini Vision Analysis: Connects directly with Google's gemini-2.5-flash model to detect fungal, bacterial, viral, and nutrient deficiency issues.

2. Live Internet Mandi Rate Tracking
- Search Grounding Integration: Uses Gemini search tools to query live web feeds for real-time commodity auction prices (₹/Quintal) matching the user's city.

3. Micro-Climate Spray Guard & Satellite Sync
- GPS Telemetry: Fetches local temperature, relative humidity, and rain probabilities via the Open-Meteo weather API.
- High-Contrast Safety Banners: Automatically generates prominent Red Warnings to stop spraying if rain will wash away chemicals, or Green Rules highlighting safe spraying windows.

4. Farmer-First Dosage & Jargon Translation
- Simplified Guidance: Eliminates complex agronomic terms (e.g., chlorosis, phytotoxicity) and translates chemical mixing ratios into household measures (e.g., "2 matchbox-fulls per 15L spray tank").

5. Dual Remedial Action Plan
- Organic & Chemical Solutions: Provides a two-step treatment roadmap separating soil-friendly bio-controls (like Neem oil) from targeted synthetic sprays.
- Smart Crop Rotation: Recommends resilient crops for upcoming seasons based on climate baselines.

6. Rural Accessibility & Hardware Integration
- Text-to-Speech Advisory: Includes an integrated audio player using the browser's native Web Speech API to read advice aloud for low-literacy users.
- GPS Agri-Store Locator: Uses live GPS coordinates to locate nearby Krishi Seva Kendras (agri-input shops) on Google Maps.
- Printable Crop Health Cards: Features print-optimized CSS (@media print) to generate clean physical or PDF reports for store owners and extension officers.
- Progressive Web App (PWA) Support: Includes an embedded manifest and dynamic Service Worker so farmers can install the app to their phone home screen.
